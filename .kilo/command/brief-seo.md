Crea un brief SEO para contenido nuevo o para reformular contenido existente.

Si se proporciona un tema o keyword, genera el brief completo.
Si no se proporciona, pregunta primero por el tema, la intención y la página objetivo.

El brief debe incluir:
1. Ficha técnica (tipo de contenido, URL, keyword principal, intención, riesgo de canibalización)
2. Metadatos propuestos (title 50-60 chars, meta description 150-160 chars, slug, canonical, OG image)
3. Estructura de headings (H1, H2s, H3s)
4. Puntos clave del contenido (primer párrafo, cuerpo, longitud objetivo, diferenciador)
5. Enlazado interno (enlaces salientes recomendados y enlaces entrantes necesarios)
6. Schema a incluir
7. CTA recomendado

Antes de proponer una URL nueva, verifica si existe canibalización con contenido existente.
