# Política de seguridad

## Alcance

Este repositorio contiene la plataforma web pública de Pineda y Asociados.
Reporte vulnerabilidades relacionadas con el código versionado aquí.

## Cómo reportar

Envíe un correo a **contacto@pinedayasociadoshn.com** con:

- Descripción del problema y pasos para reproducirlo
- Impacto estimado (confidencialidad, integridad, disponibilidad)
- Versión o commit afectado, si aplica

**No** abra issues públicos con detalles explotables.

## Qué esperar

- Acuse de recibo en un plazo razonable (días hábiles)
- Coordinación para validar y corregir el hallazgo
- Crédito al investigador si lo desea, tras la corrección acordada

## Fuera de alcance

- Ingeniería social, spam o ataques contra infraestructura de terceros (Vercel,
  Neon, Resend) fuera de este código
- Escaneos automatizados de alto volumen sin coordinación previa
