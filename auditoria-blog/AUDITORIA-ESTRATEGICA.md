## 1.1 Enfoque estratégico actualizado: SEO local + autoridad temática + conversión

El objetivo ya no es solo limpiar thin content. El blog debe convertirse en una red de contenidos jurídicos de alta calidad que cumplan tres funciones simultáneamente en cada artículo:

| Función | Descripción | Métrica |
|---------|-------------|---------|
| **Transmitir calidad y autoridad a Google** | Cada artículo debe demostrar EEAT: experiencia legal real, profundidad temática, actualidad normativa y utilidad práctica. | Posiciones GSC, impresiones, CTR |
| **Posicionar por intención de búsqueda concreta** | Cada URL responde a UNA intención: informacional, transaccional, comercial o navegacional. Sin ambigüedad. | Rankings por keyword objetivo, tráfico orgánico |
| **Convertir tráfico en lead** | Cada artículo debe guiar al usuario hacia una acción: llamada, WhatsApp, formulario o consulta. | Tasa de conversión por URL, leads generados |

**Decisión estratégica:** A partir de ahora, ningún post se publica o reescribe sin cumplir estas tres funciones. Los posts puramente informativos sin potencial de conversión se fusionan, redirigen o eliminan.

## 1.3 Nuevo criterio de calidad mínima para posts

Ningún post estratégico debe quedarse en contenido genérico de 800 palabras. Cada artículo prioritario debe incluir **obligatoriamente** estos elementos:

| Componente | Exigencia |
|------------|-----------|
| Problema legal real del usuario | El primer párrafo describe una situación concreta que el lector reconoce como propia |
| Contexto hondureño | Marco legal con artículos, decretos o resoluciones aplicables en Honduras |
| Procedimiento paso a paso | Secuencia numerada de acciones que el lector (o su abogado) debe seguir |
| Requisitos | Lista verificable de condiciones previas |
| Documentos necesarios | Enumeración concreta con nombres de documentos oficiales |
| Plazos | Días, meses o años específicos (no "en breve" o "en un plazo razonable") |
| Riesgos | Consecuencias legales de no actuar o de hacerlo incorrectamente |
| Errores frecuentes | Al menos 3 errores reales que cometen los usuarios en esa situación |
| Ejemplo práctico | Un caso hipotético con nombres, cifras y escenario hondureño |
| Cuándo contactar a un abogado | Señales concretas que indican que el usuario ya no puede actuar solo |
| CTA local | Oferta de servicio con mención de la ciudad o zona sur |
| FAQs | Al menos 3 preguntas reales con respuestas útiles (aptas para FAQ schema) |
| Enlazado interno | Enlaces a posts relacionados dentro del mismo cluster y al pilar |
| Schema recomendado | FAQPage, HowTo, Article o LegalService según el tipo de contenido |
| Meta title | 50-60 caracteres, keyword al inicio, marca al final |
| Meta description | 140-160 caracteres, propuesta de valor, CTA implícito |

**Regla:** Los posts que no puedan cumplir este estándar deben fusionarse, reescribirse totalmente o eliminarse. No se aceptan excepciones para contenido con potencial comercial.

## 7.2 Plantilla editorial obligatoria para posts de alta calidad

Todo post prioritario debe seguir esta estructura exacta:

```
# H1 orientado a intención (keyword principal, 50-65 caracteres)

## Introducción basada en problema real (100-150 palabras)
- Describe una situación que el lector reconoce como propia
- Responde directamente a la intención de búsqueda
- Incluye la keyword principal en los primeros 50 caracteres

## Respuesta directa en los primeros 100-150 palabras
- El lector debe obtener una respuesta útil inmediata
- No usar introducciones genéricas o definiciones de diccionario

## Contexto legal en Honduras (según aplique)
- Marco normativo (citar artículos, decretos o resoluciones)
- Institución reguladora o autoridad competente
- Situación actual de la legislación

## Procedimiento paso a paso
1. Paso 1 (con detalle: qué hacer, dónde, cómo)
2. Paso 2 (documentos que preparar)
3. Paso 3 (plazos a cumplir)
4. ... (máximo 8 pasos)

## Requisitos
- Lista verificable de condiciones previas

## Documentos necesarios
- Enumeración concreta con nombres de documentos oficiales hondureños

## Plazos
- Días, meses o años específicos (no "en breve" o "en un plazo razonable")

## Costos o variables económicas (si aplica)
- Rangos en Lempiras
- Factores que influyen en el costo

## Riesgos
- Consecuencias legales de no actuar o de hacerlo incorrectamente

## Errores frecuentes (mínimo 3)
1. Error 1 (qué ocurre y cómo evitarlo)
2. Error 2 (qué ocurre y cómo evitarlo)
3. Error 3 (qué ocurre y cómo evitarlo)

## Ejemplo práctico
- Caso hipotético con nombres hondureños, cifras en Lempiras y escenario realista

## Qué puede hacer el usuario solo
- Trámites o gestiones que no requieren abogado

## Cuándo necesita un abogado
- Señales concretas que indican que el usuario ya no puede actuar solo

## Preguntas frecuentes (mínimo 3, aptas para FAQ schema)
1. Pregunta real del usuario
   Respuesta clara y completa
2. ...
3. ...

## CTA local
- "Si necesita [servicio] en [ciudad], podemos ayudarle. [Acción concreta] [teléfono/WhatsApp/enlace]"

## Enlaces internos (mínimo 3)
- Enlace al pilar del cluster
- Enlace a post satélite relacionado
- Enlace a página de servicio o contacto

## Schema recomendado
- FAQPage (si tiene sección de FAQs)
- HowTo (si tiene procedimiento paso a paso)
- LegalService (si es contenido de servicio)
- Article (para contenido informativo)
```

**Regla:** Ningún post prioritario debe publicarse sin cumplir esta plantilla, salvo justificación expresa del editor jefe.
